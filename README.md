# Bookmark Studio — Releases

Public download host for **Bookmark Studio** installers and browser extensions.
The application source code lives in a separate private repository.

## Downloads

Grab the latest installers from the [**Releases**](../../releases/latest) page.

| Platform | File |
|----------|------|
| 🪟 Windows | `Bookmark Studio-Setup-<version>.exe` |
| 🍎 macOS (Apple Silicon) | `Bookmark.Studio-<version>-mac-arm64.dmg` |
| 🍎 macOS (Intel) | `Bookmark.Studio-<version>-mac-x64.dmg` |
| 🐧 Linux (Debian/Ubuntu) | `Bookmark.Studio-<version>.deb` |
| 🐧 Linux (AppImage) | `Bookmark.Studio-<version>.AppImage` |
| 🧩 Chrome/Edge/Arc extension | `bookmark-studio-chrome-extension-<version>.zip` |
| 🧩 Safari extension | `bookmark-studio-safari-extension-<version>.zip` |
