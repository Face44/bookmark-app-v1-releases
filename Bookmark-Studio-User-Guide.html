Chapter 1

What Bookmark Studio does

Bookmark Studio is a desktop app that reads your browser bookmarks and turns any of those sites into a structured design analysis you can compare, edit and export.

It works in three moves:

  1. Collect. Your bookmarks arrive either by a one-time import from your browser's bookmarks file, or live over the companion browser extension, which keeps the library in sync as you bookmark things.
  2. Analyze. Point it at a site and it reads the live page, then reports the colors, typography, layout grid, components, motion, design tokens and accessibility characteristics it found — plus the tech stack behind it.
  3. Export. Tick the parts you want to keep — colors from one site, typography from another — retune them, then save the result as a PDF, a JSON design profile, or a ready-to-use skill you can hand to an AI assistant.
Windows macOS Linux Chrome · Edge · Brave · Arc · Vivaldi Safari
✓

Everything stays on your machine. Bookmarks, analyses and thumbnails are stored in a local database. Nothing is uploaded to a Bookmark Studio server — the only outbound traffic is the app fetching the public pages you ask it to analyze, and Google sign-in.

Two things make up a complete installation: the desktop app, and the browser extension that signs you in and keeps bookmarks flowing.

You need both

The desktop app has no login screen of its own. It takes its identity from the first browser extension that signs in. So the extension is not optional — without it, the app has nothing to show.

Chapter 3

Install the desktop app

Pick the card for your operating system. Each one takes about two minutes.

Windows

Windows 10 / 11

  1. Download Bookmark Studio-Setup-<version>.exe from the Releases page.
  2. Double-click the downloaded file.

  3. Windows may show a blue "Windows protected your PC" screen. This appears because the installer isn't code-signed yet, not because anything is wrong with it.

    Click More info, then Run anyway.

  4. Choose an install folder if you want a non-default location, then click Install.
  5. The installer creates a desktop shortcut and a Start menu entry named Bookmark Studio. Launch it from either.
i

The first launch may take 10–20 seconds while the local database is created. Later launches are instant.

macOS

macOS 11 and later

  1. Download the .dmg that matches your Mac:

    • Apple Silicon (M1, M2, M3, M4) → the arm64 file
    • Intel → the x64 file

    Not sure? Click the Apple menu → About This Mac and read the Chip line.

  2. Double-click the .dmg to open it.
  3. Drag the Bookmark Studio icon onto the Applications shortcut in the same window.
  4. Eject the disk image, then open Applications and find Bookmark Studio.

  5. Right-click (or Control-click) the app icon and choose Open. In the dialog that appears, click Open again.

    Do this the first time only. After that, a normal double-click works.

!

Don't skip the right-click on first launch. The macOS build isn't notarized by Apple yet, so a plain double-click gives you "Bookmark Studio can't be opened because Apple cannot check it for malicious software" with no way forward. Opening from the right-click menu gives you the Open button that a double-click doesn't.

If macOS still refuses, open System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to the Bookmark Studio message.

Linux

Ubuntu, Debian, Fedora and others

Option A — .deb package (Ubuntu, Debian, Mint, Pop!_OS)

  1. Download Bookmark Studio-<version>.deb.

  2. Double-click it to open your software installer, or install from a terminal:

    sudo apt install ./"Bookmark Studio-2.1.1.deb"

    sudo dpkg -i works too, but apt is worth preferring — it pulls in any missing system libraries for you.

  3. Launch Bookmark Studio from your applications menu, or run bookmark-studio in a terminal.

Option B — .AppImage (any distribution, no install)

  1. Download Bookmark Studio-<version>.AppImage.

  2. Make it executable — right-click → Properties → Permissions → tick Allow executing file as program, or from a terminal:

    chmod +x "Bookmark Studio-2.1.1.AppImage"

  3. Double-click to run it, or:

    ./"Bookmark Studio-2.1.1.AppImage"
i

On a minimal desktop install you may need a few system libraries the .deb pulls in automatically. If the AppImage refuses to start, install them by hand:

sudo apt install libgtk-3-0 libnotify4 libnss3 libxss1 \
  libxtst6 xdg-utils libatspi2.0-0 libuuid1 libsecret-1-0

On Fedora the equivalent packages are gtk3, libnotify, nss, libXScrnSaver and libsecret.

The first time you open Bookmark Studio on any platform it shows the End-User License Agreement. Read it, then click I Accept. Declining closes the app — acceptance is required to use it.

Chapter 4

Install the browser extension

The extension signs you in and streams bookmark changes to the desktop app in real time. Install it once per browser you use.

!

Keep the desktop app running. The extension talks to Bookmark Studio over a local connection on your own machine. If the app is closed, the extension shows Disconnected and sign-in will fail.

Chromium browsers

Chrome, Edge, Brave, Arc, Vivaldi, Chromium

All of these share one build, so the steps are identical — only the address you type in step 3 differs.

  1. Download bookmark-studio-chrome-extension-v<version>.zip from the release Assets list.

  2. Unzip it, and put the resulting folder somewhere permanent — your Documents folder is fine. The browser reads the extension from this folder every time it starts, so deleting or moving it later breaks the extension.

  3. In your browser, open the extensions page:

    BrowserAddress
    Chromechrome://extensions
    Edgeedge://extensions
    Bravebrave://extensions
    Vivaldivivaldi://extensions
    Arcarc://extensions
  4. Turn on Developer mode — the toggle is in the top-right corner on Chrome, Brave and Vivaldi, and in the left sidebar on Edge.
  5. Click Load unpacked and select the unzipped folder from step 2. Select the folder itself, not a file inside it.

  6. Bookmark Studio Sync now appears in your extension list. Pin it: click the puzzle-piece icon in the toolbar, then the pin next to Bookmark Studio, so its icon stays visible.

✓

Already installed the desktop app? The same extension ships inside it, so you can skip the download. Click Open the extension folder on the app's welcome screen and it opens the folder to use in step 4 — no unzipping needed.

i

Developer mode has to stay on. Chromium browsers disable unpacked extensions when it's switched off. Some may also show a "disable developer mode extensions" prompt at startup — dismiss it with Cancel or Keep.

macOS only

Safari 17 or later

Safari can't load an extension folder the way Chromium browsers can. Apple requires every Safari extension to be wrapped inside a small native app, and that wrapping has to happen on your own Mac using Apple's own tool.

!

This one needs Xcode. Unlike the Chromium extension, the Safari download is source that you convert and build yourself. You'll need a Mac with Xcode installed — a free download from the Mac App Store, around 7 GB — and you'll be running two terminal commands.

If that's more than you want to take on, use Chrome, Edge, Brave, Arc or Vivaldi instead. The desktop app behaves identically whichever browser feeds it.

  1. Download bookmark-studio-safari-extension-v<version>.zip from the release Assets list and unzip it.

  2. Open Terminal and convert the unzipped folder into an Xcode project, replacing the path with wherever you unzipped it:

    xcrun safari-web-extension-converter ~/Downloads/safari \
  --project-location ~/Downloads/safari-xcode --swift

    Answer yes to the prompts it shows.

  3. Open the generated project in Xcode, then click Run (the ▶ button). A small window appears — this is the host app whose only job is to register the extension with Safari. You can close it once it's opened.
  4. In Safari, open Safari → Settings → Extensions.

  5. Tick the checkbox next to Bookmark Studio Sync.

    If it isn't listed, enable Safari → Settings → Advanced → Show features for web developers, then tick Allow unsigned extensions in the Developer tab and check again.

  6. When Safari asks for permission to read your bookmarks, choose Allow. Without this the extension connects but has nothing to send.
  7. Click the Bookmark Studio icon in Safari's toolbar to open the popup and sign in.

The unzipped folder also contains README-XCODE.md with the same steps and notes on Safari-specific quirks.

i

If the toolbar icon isn't visible, right-click Safari's toolbar → Customize Toolbar and drag the Bookmark Studio icon into place.

Safari 17 or later is required. Earlier versions don't support the extension format this build uses.

Sign in from the extension popup

This is the step that unlocks the desktop app.

  1. Make sure Bookmark Studio (the desktop app) is open.
  2. Click the Bookmark Studio icon in your browser toolbar.

  3. Choose how to sign in:

    • Continue with Google — opens a Google sign-in page in a new tab. Pick your account, approve, and return to the browser.
    • Create account — enter an email address and a password of at least 8 characters. This account lives only on your computer.
  4. The popup switches to a status view showing your email and a green Connected badge.
  5. Switch to the desktop app. The welcome screen is replaced by your library, and your email appears at the bottom of the left sidebar.
✓

Use several browsers at once. Install the extension in each one and sign in with the same account. All their bookmarks merge into one library, deduplicated by address, with a badge on each card showing which browser it came from. Signing out from one browser signs you out everywhere.

Chapter 5

First run & filling your library

Once you're signed in, get your bookmarks into the app and learn your way around the window.

Two ways to add bookmarks

They work together — most people do the import once for their existing collection, then let the extension keep things current.

ImportLive sync
What it bringsEverything already in your browser, with its folder structureNew, changed and deleted bookmarks as they happen
How oftenWhen you ask for itContinuously, while the app and browser are both open
Where items landIn the folder tree, mirroring your browserIn All Bookmarks, with a browser badge

Import your existing bookmarks

  1. Click Import bookmarks on the welcome screen, or from the toolbar if you already have a library.

  2. The dialog offers two routes:

    • Detected browser — if Bookmark Studio found your browser's bookmarks file, it names the browser and offers a one-click import. This is the easy path.
    • Choose a file — pick a bookmarks file yourself. Use this for a second browser profile, a browser that wasn't detected, or a backup.
  3. Click the import button and wait a few seconds. Large libraries take longer; the button shows progress.
  4. The folder tree fills in on the left and thumbnails start appearing in the grid.
i

Close your browser first for the cleanest import. Browsers hold their bookmarks file open, and a file being written to while it's read can produce a partial import. If the import looks short, quit the browser and run it again.

Thumbnails

Bookmark Studio fetches a preview image for each site in the background — the page's own social preview image where one exists, otherwise a lettered placeholder. They're cached on disk, so this only happens once per site. On a large library expect the grid to keep filling in for a minute or two after import.

Chapter 6

Analyze one site

The core action: point Bookmark Studio at a bookmarked site and get its design broken down into readable layers.

Run the analysis

  1. Hover over any card in the grid. An overlay appears across it.
  2. Click Analyze design.

  3. A full-window view opens with the site's name and address at the top and its screenshot below. While it works you'll see a loading state — usually 5–15 seconds, longer for heavy sites.

  4. When it's done, the analysis appears as a series of sections you can scroll through.

What you get back

Each analysis is organised into sections. A site that doesn't use something — no animation, no design tokens — simply won't show that section.

SectionWhat it tells you
Overall moodA plain-language read of the design's character, inferred from everything else below.
Built withThe frameworks, libraries and platforms detected behind the site.
ColorThe palette, ordered by how much of the page each color occupies. Click any swatch to copy its hex code. A Color system block underneath adds the relationships — harmony, contrast pairings, roles.
TypographyThe typefaces in use and the full size scale, from smallest label to largest heading, with the weights actually observed on the page. A Type system block shows the ratio and hierarchy.
LayoutContainer widths, grid columns, gutters and the spacing rhythm the page is built on.
ComponentsRecurring UI pieces found on the page — buttons, cards, inputs — including a detailed read of the primary button's shape, padding and states.
Motion & effectsTransition durations and easing curves, plus gradients and glass/blur effects.
Design tokensNamed CSS custom properties the site exposes — the closest thing to reading its design system directly.
Accessibility & themeContrast characteristics, dark-mode support and related signals.

Quick actions on a finished analysis

Scroll to the bottom of the analysis for three buttons:

  • Save as PDF — the complete analysis as a formatted PDF, straight to your downloads folder.
  • Export design profile — the analysis as machine-readable data. See Chapter 9.
  • Analyze again — discards the cached result and re-reads the live site. Use this when a site has been redesigned.
i

Results are cached. Analyzing the same site again is instant, because the result is stored locally. Only Analyze again forces a fresh read.

!

Some sites read better than others. Sites that build their styling at runtime, or that render everything into a canvas, expose less to inspect — colors may be approximated from the screenshot instead of read exactly, and some sections may come back thin. When that happens the app labels the section so you know the values are estimates. Login-walled pages return only what a signed-out visitor can see.

Press Esc or click the ✕ in the top-right corner to close the analysis and return to your library.

Chapter 7

Analyze several sites at once

Compare up to five sites side by side in a single view — the fastest way to see how designs in a category differ, and the starting point for mixing them.

Select and run

  1. Click Select in the toolbar. Checkboxes appear on every card and a selection bar drops in below the toolbar.

  2. Tick the cards you want. The bar keeps a running count — 3 of 5 selected.

    Use Select all to take the first five in the current view, or Clear to start over.

  3. Click Analyze Selected (3).

  4. The comparison view opens immediately with one column per site. Each column loads on its own, so the fast ones are readable while the slow ones are still working. The header counts progress — 2 of 3 analyzed.

i

Five is the limit. Past five, columns get too narrow to compare properly and analyses take too long to run together. Once you've hit five, other checkboxes stop responding until you untick something.

Reading the comparison view

Each column is an independent, complete analysis — the same sections in the same order as the single-site view, so you can read straight across a row to compare like with like.

  • Each column scrolls on its own. Scroll one to Typography and compare it against another at your own pace.
  • With four or five sites the row scrolls sideways rather than squeezing columns — every column stays readable.
  • If a site fails to analyze, only its column shows the error. The rest are unaffected, and you can retry that one from inside its column.

Press Esc to close the comparison. Your selection is preserved, so you can adjust it and run again without starting over.

Chapter 8

Pick sections & attributes from different sites

This is where Bookmark Studio stops being a viewer and becomes a design tool: take the colors from one site, the typography from another, the layout from a third, and assemble them into one profile.

The idea in one line

Every section of every analysis carries a Select checkbox. Tick a section to claim that aspect from that site. Tick sections from different columns to build a blend.

i

This works with one site too. Open a single analysis and the same checkboxes are there. Selecting from one site just means picking which parts of it you want to keep — the rest of the flow is identical.

Step 1 — Tick the sections you want

Each section header has a small Select box in its top corner. Tick it and that section is claimed.

The rule enforced throughout: one source per aspect. Once you've taken Color from site A, the Color checkbox on sites B and C locks — you can't take a palette from two places at once. Untick site A's Color to release it. A single site can contribute as many aspects as you like.

The nine selectable aspects:

AspectWhat comes along with it
Overall moodThe design's character summary. Always available on any analysis.
Built withThe detected tech stack.
ColorThe palette, plus the derived color system — harmony, contrast pairings, roles.
TypographyTypefaces, the full size scale, observed weights and the type system.
LayoutContainer widths, grid, gutters and spacing rhythm.
ComponentsThe component inventory and the primary button specification.
Motion & effectsDurations, easing curves, gradients and blur/glass effects.
Design tokensThe named CSS variables the site exposes.
Accessibility & themeContrast behaviour and dark-mode support.
i

A checkbox that's greyed out and won't tick means that site has nothing to offer for that aspect — no animation was found, no tokens were exposed. Sections are only offered when there's real data behind them, so you never end up with an empty block in your export.

Step 2 — Narrow down to individual attributes

Whole sections are the coarse control. Inside several of them you can go item by item.

Once a section is ticked, its individual items become tickable too. They all start ticked — you're removing what you don't want, not adding what you do.

Inside…You can keep or drop…
ColorEach swatch individually — drop the four greys and keep the two brand colors.
TypographyEach row of the size scale, each typeface, and each observed weight and size.
Motion & effectsEach gradient, duration, easing curve and motion usage.
Design tokensEach named token.
!

Unticking a section resets its narrowing. If you untick Color and re-tick it — or move Color to a different site — your per-swatch choices are cleared and the full palette comes back. Do your narrowing after you've settled which site each aspect comes from.

Step 3 — Review & edit

The header keeps a live count — 3 aspects picked — and lights up the Review & edit button as soon as anything is ticked. Clear next to it wipes every selection.

Click Review & edit and your picks are assembled into a single combined profile, shown grouped by aspect. Each block is labelled with the site it came from, so you can always see where a value originated.

Retuning the palette

Colors are the one thing you can change in this window. Everything else is shown for reference and travels through unchanged.

  • Change a color — use the color picker swatch, or type a hex code directly into the field beside it.
  • Set emphasis — give each color a percentage describing how much of the design it should occupy. A conventional split is a dominant color around 60%, a secondary around 30%, and an accent around 10%.
  • Automatic rebalancing — the group always totals exactly 100%. Raise one color and the others drop proportionally; lower one and they rise. You never have to do the arithmetic.
  • Reset — returns every color to an equal share so you can start the distribution again.

Step 4 — Export

Three buttons sit in the review window's header. All three use exactly what's on screen, including your color edits.

ButtonProduces
Save PDFA formatted document of the combined profile — for sharing, printing or attaching to a brief.
Export profileA JSON file of the profile — for feeding into other tools.
Download skillA packaged skill folder with your profile inside. See the next chapter.
✓

A worked example. To build a profile that's "this brand's colors, that magazine's typography, that product site's spacing":

  1. Select all three bookmarks and analyze them together.
  2. Tick Color on the brand column, then untick the greys so only the brand colors remain.
  3. Tick Typography on the magazine column.
  4. Tick Layout on the product column.
  5. Click Review & edit, set the brand color to 60% and the accent to 40%.
  6. Click Download skill.

Chapter 9

Download the skill

A skill packages your design profile together with the instructions an AI assistant needs to actually build with it — so you can say "make this page match my profile" and get something faithful back.

What's inside

The download is a single .zip. Unzipped, it's a folder called reference-design-studio containing:

  • Your profile, in a profiles folder — the colors, type, layout and everything else you selected.
  • Reference documentation — detailed guidance on how each part of a design profile should be interpreted and applied: color systems, type scales, spacing, components, motion, accessibility.
  • Presets for common jobs — using a reference as loose visual inspiration, extending an existing brand, or adapting a full design system.
  • Examples showing what good profiles and good prompts look like.

Three ways to export

From a single analysis, click Export design profile at the bottom of the analysis. A menu offers three destinations:

OptionWhat it doesUse it when
Save to file… Opens a save dialog and writes the profile as a JSON file wherever you choose. You just want the data, or you're feeding it into your own tooling.
Send to design skill Drops the profile straight into the skill folder bundled with the app and marks it as the active profile — no dialog, no file handling. You're working on this machine and want it available immediately.
Download skill (.zip) Bundles the complete skill, with your profile inside, into a .zip you choose the location for. You're sharing it, or loading it into an AI assistant elsewhere.

From the Review & edit window the same choices appear as the Export profile and Download skill buttons in the header.

Downloading the skill, step by step

  1. Finish an analysis, or assemble a blend and open Review & edit.
  2. Click Download skill — or Export design profile → Download skill (.zip) from a single analysis.
  3. Choose where to save it. The suggested filename is based on the site, for example stripe-com-skill.zip.
  4. A confirmation appears — Skill downloaded: stripe-com-skill.zip.
  5. Unzip the file. You'll get a reference-design-studio folder.

Using it with an AI assistant

  1. Install the unzipped reference-design-studio folder as a skill in your assistant, following that tool's own instructions for adding skills.

  2. Ask for what you want in plain language, naming the profile:

    "Use the reference-design-studio skill with my stripe-com
profile to build a pricing page for a project-management app."
  3. The assistant reads your profile — real colors, real type scale, real spacing — and the guidance that ships alongside it, and builds to those values rather than guessing.
✓

One skill, many profiles. A downloaded skill can hold more than one profile. Export several and drop them all into the skill's profiles folder, then name the one you want in each request — "use the acme profile", "use the editorial profile".

i

If Send to design skill or Download skill can't find the bundled skill folder — an unusual installation, for instance — the app falls back to a normal save dialog and writes the profile as JSON, telling you it did so. Nothing is lost.

Back up

Copy the whole folder. Restore by putting it back with the app closed.

Start fresh

Close the app, delete the folder, and reopen. You'll be asked to accept the licence and sign in again, then you can re-import.

Uninstall

  • Windows — Settings → Apps → Bookmark Studio → Uninstall
  • macOS — drag the app from Applications to the Trash
  • Linux — sudo apt remove bookmark-studio, or delete the AppImage file

Uninstalling leaves the data folder in place. Delete it too if you want everything gone. Remove the extension separately from your browser's extensions page.

Analysis fails with an errorThe site may be unreachable, behind a login, or blocking automated requests. Open it in your browser to confirm it loads, then click Analyze again.
Colors look wrong or thinSites that build their styling at runtime expose less to inspect. The section is labelled when values are approximated. You can correct any color by hand in Review & edit.
Analysis is out of date after a redesignClick Analyze again — results are cached until you do.
A Select checkbox won't tickEither that site has no data for the aspect, or another site has already claimed it. Untick it on the other column to release it.
Review & edit is greyed outNothing is selected yet. Tick at least one section.
My per-swatch choices disappearedUnticking a section — or moving it to another site — resets its narrowing. Do the narrowing last.
Export saved a JSON file instead of a skillThe bundled skill folder wasn't found, so the app fell back to saving the profile. The profile itself is intact.
